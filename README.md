# 《无喉之歌》The Voice Without a Throat
**An Opus 5.5 Film** · 4:07 · 1280×720 · 24 fps · 5,928 frames

每一帧画面、每一个音符都由代码生成：没有摄像机、没有麦克风、没有演员、没有素材文件。
Every frame and every note is generated by code. No cameras, no microphones, no actors, no samples.

| 文件 | 作用 |
|---|---|
| `tl.js` | 时间线：字幕卡、歌词、片尾终端字幕 |
| `audio.js` | 纯 Node 合成器：共振峰歌声、钢琴、弦垫、合唱、太鼓、BRAAAM、混响、母带 → `out/audio.wav` + 驱动画面的音频包络 `out/env.js` |
| `engine.js` | Three.js 场景与导演系统：粒子隧道、少女、房间、城市、演唱会、雪、终端 |
| `render.js` | Playwright 逐帧离线渲染（确定性，可断点续渲） |
| `preview.js` | 抽帧预览：`node preview.js 20,88,190 640` |
| `build.sh` | 一键构建 |
| `AGENTS.md` | 给 AI 助手的操作手册（让 Claude / ChatGPT / Cursor 等直接帮你操作） |
| `.github/workflows/render.yml` | GitHub Actions 云端分片渲染 |

## 方式 A：GitHub Actions（推荐，不占你的电脑）
1. 新建一个 GitHub 仓库，把本文件夹全部内容（含隐藏目录 `.github/`）推上去。
2. 打开仓库 **Actions → Render film → Run workflow**（默认 12 个分片并行）。
3. 大约 20–40 分钟后，在本次运行页面底部 **Artifacts** 下载 `film-the-voice-without-a-throat`（解压得到 `film.mp4`）。

公开仓库的 Actions 免费；私有仓库会消耗免费分钟数（约 150–250 分钟）。

## 方式 B：本机构建（macOS / Linux / Windows WSL）
依赖：Node 18+、Python 3、ffmpeg。
```bash
bash build.sh                 # 输出 film.mp4
GPU=1 bash build.sh           # 有独立显卡时更快
START=4560 END=4800 bash build.sh   # 只渲染一段（帧号 = 秒 × 24），输出 clip_*.mp4
```
中途中断可以直接重跑，已渲染的帧会跳过。字幕使用 Noto Sans/Serif CJK 字体，缺字体时 Linux 可装 `fonts-noto-cjk fonts-noto-cjk-extra`。
